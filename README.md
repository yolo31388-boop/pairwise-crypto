# 游戏内加密算法与密码学系统

## 项目描述

游戏内加密算法与密码学系统的bug修复项目。核心模块 `security/crypto.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 对称加密完全没做数据都是明文的
- 非对称加密完全没做不能用公钥加密私钥解密
- 哈希完全没做用的是MD5而且没有加盐
- 数字签名完全没做存档被篡改了也检测不到
- 密钥管理完全没做加密密钥硬编码在代码里

## 运行测试

```bash
python -m pytest tests/test_crypto.py -q
```

修复目标：所有 16 个测试全部通过。
